# إضافة قطاع أو حاجة جديدة، والتعديل على الموجود

## بدون برمجة (من داخل التطبيق)

| تريد | من أين |
|---|---|
| شخص جديد / تعديل اسم | الأشخاص ← «شخص»، أو زر «+ جديد» بجانب أي قائمة أشخاص |
| بند مصروف جديد (بوحدة مثل طن/كيلو) | المزيد ← القوائم ← «+ بند» |
| نوع بيض جديد (كسر، صغير…) | المزيد ← القوائم ← «+ نوع» |
| مجموعة (كاتيجوري) تجمع أشياء | المزيد ← المجموعات، ثم اخترها من إعداد الدورة |
| موعد متكرر (صيانة، تجديد، تحصيل) | المزيد ← التذكيرات |
| تغيير مدة بند صيانة العربية، إيقافه، أو بند صيانة خاص | العربية ← الإعداد ← جدول الصيانة |
| تصحيح أي رقم مُدخل | اضغط الحركة ← تعديل (القديم يبقى في السجل) |

## ببرمجة (قطاع جديد أو حساب جديد) — عن طريق Claude Code

1. افتح جلسة Claude Code على ريبو `personal-assistant`.
2. اكتب طلبك بوضوح، مثلاً:
   - «أضف قطاع **السلف والأمانات**: سلفة لي أو عليّ لشخص، بتاريخ بداية وموعد رجوع، وسداد على دفعات، وتذكير قبل الموعد بأسبوع، وتظهر في وضعي المالي.»
   - «أضف قطاع **النخل**: عدد النخل بالأصناف، مواعيد التلقيح والري والتسميد كتذكيرات، ومصروفات، وبيع المحصول بالكيلو.»
   - «أضف لقطاع الدواجن بند بيع **كسر بيض** وتقرير مقارنة بين دورتين.»
3. Claude يضيف الوحدة بجانب الموجود، يكتب اختباراتها، يشغّل كل الاختبارات، ويرفع التحديث.
4. بعد النشر يظهر في التطبيق شريط «يوجد تحديث جديد» ← **تحديث الآن**. بياناتك لا تتأثر.

## لماذا لا يضيع شيء مع كل مرحلة؟

- **البيانات منفصلة عن الكود.** التحديث يغيّر ملفات التطبيق فقط؛ قاعدة البيانات على هاتفك لا تُمس.
- **سجل لا يُمسح منه شيء.** كل إدخال «حدث» محفوظ للأبد، والحالة تُحسب منه. التعديل حدث جديد.
- **أحداث عامة ثابتة.** القطاع الجديد يضيف «أنواعاً» داخل نفس الأحداث، فلا يحتاج تحويل بياناتك القديمة.
- **لو احتاج تغيير شكل بيانات قديمة** (نادر): ترحيل مرقّم يأخذ نسخة تلقائية قبله، ويتحقق من الناتج، ويكتب ككتلة واحدة؛ أي فشل = لا تغيير.
- **الاختبارات** تحرس الحسابات (مثل: مجموع التوزيع = صافي الشهر، النقدية = أرصدة الشركاء) قبل أي نشر.

## للمطوّر: هيكل الوحدة

```
app/src/core/modules/<id>/index.js    التعريف: الأنواع، التحقق، الوصف، التذكيرات، البنود المالية
app/src/core/modules/<id>/calc.js     الحسابات (دوال خالصة)
app/src/ui/modules/<id>/index.js      المسارات، بطاقة الرئيسية، أرصدة الشخص، تحرير القيود
app/src/ui/modules/<id>/screens.js    الشاشات
app/src/ui/modules/<id>/forms.js      النماذج
tests/unit/<id>.test.mjs              اختبارات المنطق
```

ثم سطر في `core/modules/index.js` وسطر في `ui/modules/index.js`. التفاصيل والقواعد في `CLAUDE.md`.
