# النشر

التطبيق ملفات ثابتة بمسارات نسبية. الريبو `personal-assistant` **عام لكنه كود فقط**: لا بيانات فيه أبداً (`input/` و`output/` و`*.xlsx` في `.gitignore`، واختبار يفحص ألا يظهر أي اسم من بياناتك في أي ملف).
البيانات نفسها على هاتفك وفي Drive الخاص بك فقط، ولا يمكن لأحد الوصول لها من الموقع.

> **تنبيه:** رابط التطبيق هو «عنوان» بياناته على الهاتف. تغيير اسم الريبو أو المستخدم أو الاستضافة = تطبيق جديد ببيانات فارغة. الانتقال يكون فقط بـ: تصدير نسخة ← التثبيت من الرابط الجديد ← الاستيراد.

## النشر الأول (مرة واحدة)
1. ادمج فرع العمل في `main` (أو اطلب من Claude Code فتح Pull Request ثم ادمجه).
2. في صفحة الريبو: **Settings ← Pages ← Build and deployment ← Source: GitHub Actions**.
3. افتح تبويب **Actions**: سير العمل «نشر التطبيق على GitHub Pages» يعمل تلقائياً (أو اضغط Run workflow).
4. بعد دقيقة يعمل الرابط: `https://saidelnagar-creator.github.io/personal-assistant/`
5. أكمل من `INSTALL_IPHONE.md`.

## نشر تحديث
1. التعديل في جلسة Claude Code ← الاختبارات تنجح ← دمج في `main`.
2. سير العمل ينشر تلقائياً. على الهاتف يظهر «يوجد تحديث جديد» ← «تحديث الآن». البيانات لا تُمس.

## ملاحظات
- التطبيقان (دفتر الخير ومساعدي) على نفس النطاق `saidelnagar-creator.github.io` لكن كل منهما بقاعدة بيانات وكاش ومفاتيح منفصلة تماماً.
- النسخ التلقائي على Drive: نفس «معرّف العميل» من Google Cloud يصلح للتطبيقين؛ أضف رابط هذا التطبيق في Authorized redirect URIs.
- بديل للاستضافة: Cloudflare Pages أو Netlify برفع مجلد `app/`. اختر استضافة واحدة قبل التثبيت والتزم بها.
