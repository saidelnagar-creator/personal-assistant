# المراحل

| المرحلة | المحتوى | الحالة |
|---|---|---|
| 1 | الأساس المشترك (السجل، الأشخاص، المجموعات، التذكيرات، النسخ الاحتياطي، القفل، وضعي المالي) + **الدواجن** | ✅ |
| 2 | **الوضع المالي الكامل**: ✅ السلف لي وعليّ (فلوس/ذهب/عملات، مواعيد وأقساط، القيمة وقتها ودلوقتي)، ✅ الأمانات، ✅ الجمعيات (عضو ومدير) — باقي: السيولة (كاش، بنك، محافظ)، الممتلكات القابلة للبيع بسعرها التقديري، الدخل المتوقع (إيجار، أرباح) ومقارنته بما عليّ | جزء كبير ✅ |
| 3 | **الأرض المؤجرة** (المستأجر، القيمة، مواعيد التحصيل) و**النخل** (العدد، مواعيد الخدمة، بيع المحصول) | |
| 4 | **المنحل**: الخلايا في كل موسم، نسبة التشغيل للشريك، حسابه الجاري، القطفة والتعبئة، التوزيع والهدايا، تكلفة الكيلو | |
| 5 | **العربية**: الصيانة بالوقت وبالكيلومترات، الأعطال، التصليحات وقطع الغيار، التعديلات المخططة، التذكير بالمواعيد | ✅ (اتعملت قبل المرحلة 2 بطلبك) |

اختيارية لاحقاً: ربط التذكيرات بتقويم Google، مشاركة تسوية الشهر صورةً، مقارنة الدورات.
