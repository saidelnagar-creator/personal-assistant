# الأمان وحماية البيانات

## أين البيانات ومن يراها؟
| | |
|---|---|
| البيانات | على هاتفك فقط (IndexedDB). لا خادم ولا قاعدة بيانات على الإنترنت. |
| الريبو والموقع | كود التطبيق فقط. فتح الموقع من جهاز آخر يعطي تطبيقاً فارغاً. |
| الاتصال الخارجي | لا شيء افتراضياً. سياسة CSP تمنع أي كود أو اتصال خارجي، إلا `www.googleapis.com` للنسخ على Drive إن فعّلته بمعرّف عميلك. |
| Drive | صلاحية `drive.file` فقط: التطبيق يرى ملف نسخته فقط في حسابك. يمكن تشفير الملف المرفوع بكلمة سر. |
| القفل | رقم 4–8 أرقام (بصمة مملّحة ومكررة)، انتظار متضاعف بعد 5 محاولات خاطئة، قفل تلقائي بعد دقيقتين في الخلفية. |
| إخفاء الأرصدة | حاجز عرض لمن بجانبك، ليس تشفيراً. |
| النسخة المشفّرة | AES-256-GCM بمفتاح PBKDF2 (250 ألف دورة). لا استرجاع لكلمة السر. |

## ضد الضياع
| الخطر | الحماية |
|---|---|
| خطأ إدخال أو حذف | لا شيء يُمحى: الإلغاء والتعديل قيود جديدة. |
| عملية حساسة (استيراد، استرجاع، ترقية) | نسخة تلقائية قبلها (آخر 12)، والعملية ذرية. |
| تحديث التطبيق | الكود منفصل عن البيانات؛ مختبر أن السجل لا يتغير بعد التحديث. |
| تلف قاعدة البيانات وحدها | نسخة مرآة داخلية تلقائية + عرض الاسترجاع عند التشغيل. |
| فقد الهاتف أو حذف التطبيق | **نسخة خارج الهاتف فقط**: التصدير إلى Drive، أو النسخ التلقائي المستمر. التطبيق يذكّرك. |

## عليك
1. رمز دخول و Face ID على الهاتف. 2. قفل التطبيق. 3. نسخة على Drive أسبوعياً (أو التلقائي). 4. التحقق بخطوتين على GitHub و Google. 5. لا تحذف الأيقونة ولا تغيّر الرابط قبل التصدير.
