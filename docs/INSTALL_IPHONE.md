# التثبيت على iPhone

1. افتح الرابط في **Safari** (ليس Chrome): `https://saidelnagar-creator.github.io/personal-assistant/`
2. زر المشاركة ⬆️ ← **إضافة إلى الشاشة الرئيسية** ← إضافة.
3. افتح التطبيق **من الأيقونة دائماً** (لا من Safari) — بيانات التطبيق المثبَّت محمية من المسح التلقائي.
4. المزيد ← الإعدادات ← **تفعيل القفل** (رقم 4–8 أرقام).
5. لو عندك ملف استيراد من الإكسيل: احفظه في «الملفات» ثم المزيد ← النسخ الاحتياطي ← استيراد نسخة احتياطية.
6. أول نسخة احتياطية: المزيد ← النسخ الاحتياطي ← تصدير ← اختر **Drive**.

## قائمة تحقق على الجهاز الحقيقي
- [ ] يفتح بدون إنترنت (وضع الطيران) بعد أول فتح.
- [ ] القفل يظهر عند الفتح وبعد دقيقتين في الخلفية.
- [ ] التصدير يفتح قائمة المشاركة وفيها Drive والملفات.
- [ ] الاستيراد يقبل الملف ويعرض المعاينة.
- [ ] حقول الإدخال لا تكبّر الشاشة عند الضغط عليها.
